# Task 7 Calibration and Difficulty Protocol

Status: pre-registered and committed before calibration execution.

Version: task7_sobol512_difficulty_ladder_v1

Exactly 512 candidates are generated by a deterministic, unscrambled,
12-dimensional Sobol base-2 design (m = 9). Unit coordinates are decoded
through the already pre-registered linear/log search transforms. Candidate
order is fixed. The calibration loop has no optimizer object, ask, tell,
history, acquisition function, or adaptive stopping.

Every calibration candidate receives the identical Full evaluator: one
independent real SKY130 OP process, one independent differential open-loop AC
process, and one independent unity-follower transient process. Final hard
specifications are selected only by applying the ladder below to the complete
stored measurements.

The selection rule is mechanical:

1. Compute simultaneous feasible density for every ladder row.
2. Among rows with density in the inclusive 0.2%--2.0% target interval,
   select the most stringent row (largest row number).
3. If no row is in range, select the row whose density has the smallest
   absolute log-distance from 0.6325% (the geometric midpoint); ties select
   the more stringent row.
4. Write the chosen thresholds into the frozen YAML and bind the complete
   resolved benchmark, model hashes, search prior, semantics, and cost
   contract with one SHA-256 before any optimizer run.

Calibration measurements may select difficulty only. They cannot initialize,
rank, seed, warm-start, or otherwise inform Random, DE, TPE, or BO.
